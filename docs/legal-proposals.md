## 4つの論点の確認結果（専門家に相談するときの要点）

### 1. 運営者の表示
- 反映：「AIMUSE運営事務局（個人による運営）」、氏名・住所は「ご請求があった場合に遅滞なくお知らせします」
- 根拠：個人情報保護法32条1項は、事業者の氏名・住所などを「本人の知り得る状態（本人の求めに応じて遅滞なく回答する場合を含む。）」に置くことを求めています。請求に応じて回答する形でも満たせます
- 特定商取引法の表示：有料の販売をしていないため、現時点では不要の見込み。**有料の機能や広告収入の仕組みを始めるときは、改めて確認が必要**
- 運用で必要なこと：請求が来たときに、氏名・住所を遅滞なく回答できるようにしておく

### 2. 管轄裁判所
- 反映：「運営者の住所地を管轄する地方裁判所または簡易裁判所」を第一審の管轄とし、「利用者が消費者である場合は、利用者の住所地の裁判所に訴えることを妨げない」と明記
- 理由：消費者向けの規約で、事業者の所在地だけに限る「専属的」合意管轄は、消費者契約法10条や定型約款の規定（民法548条の2第2項）により無効とされるおそれがあります。消費者の住所地での提訴も認める形にしました
- **未確定（専門家に確認）**：この書き方で十分か

### 3. 個人情報の保護（外国の事業者への委託）
- 反映：委託先（Supabase・Cloudflare・Google）が米国の事業者であること、データの保存場所が日本（東京）であること、米国の制度を確認したうえで委託先の安全管理措置を確認していること。安全管理措置（管理者アカウントは1つで、二段階認証）も追加
- 根拠：個人情報保護委員会の Q&A では、外国の事業者のクラウドを使う場合、提供に当たらない場合でも「外的環境の把握」が必要で、事業者とサーバーがある外国の名称と、講じた措置の内容を本人が知り得る状態に置く必要があるとされています
- **前提（あなたの作業）**：Supabase と GitHub の二段階認証を有効にすること（記載内容を事実にするため）
- **未確定（専門家に確認）**：Supabase が委託先として個人データを「取り扱う」と評価される場合、28条（外国にある第三者への提供）の同意・情報提供が必要かどうか

### 4. BOOST での楽曲の紹介
- 反映：ガイドラインの利用許諾に、「本サービスの紹介のため、公開中の楽曲の曲名・アーティスト名・ジャンル・ジャケット画像・楽曲ページへのリンクと、紹介文を、運営者の SNS アカウントや紹介用ページに掲載すること（音源は掲載しない）」を追加。投稿者は掲載の停止を求められる
- 確認した事実：BOOST が使うのは、曲名・アーティスト名・ジャンル・ジャケット画像・紹介ページへのリンクで、音源は使っていません
- 既存の投稿者への影響：本番の投稿者は運営者本人だけのため、規約の変更への同意を改めて得る必要は今のところありません
- **未確定（専門家に確認）**：SNS に画像を投稿すると、SNS の運営会社にも利用許諾を与える規約になっていることが多いため、投稿者からの許諾の範囲がそれを含むと読めるか。ジャケット画像に人物が写っている場合の肖像権
