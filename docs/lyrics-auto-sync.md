## 流れと規則
- 解析待ちに入る：管理者が承認して公開したとき／公開中の曲の歌詞が変わったとき／長さが登録されたとき／運営の登録／投稿者の「AI で合わせ直す」
- 入らない：審査待ち・却下・非公開、歌詞なし（歌詞が入れば自動で入る）、長さ未登録（入れば自動）、10分超、20MB 超、**手動の同期がある曲**（本人が頼んだときだけ解析し、結果は提案だけ）
- 重複しない：1曲1行（主キー）。同じ歌詞で解析待ち・確認待ち・使用中・不採用・打ち切りなら登録しない
- 結果はすべて**確認待ち**（`auto_apply` は false）。再生画面には出さず、従来どおり歌詞の全文表示のまま
- 投稿者（または運営）が編集画面で聞いて確かめて「保存する」→ 同期になる。手を加えなければ `auto`、直せば `mixed`
- 投稿者が手動で合わせた同期は、運営でも提案で置き換えられない（本人の操作だけ）
- 人が直した量（AI との時刻の差：中央値・90%・最大、直した行数）を記録し、管理画面に精度として表示

## 時刻の品質の検査（結果ごと）
照合率 60%以上に加えて：推定の行が5行以上続かない／0.3秒未満の間隔が1割以下／曲の長さを超えない／最初から最後の行までが曲の3割以上／時刻がある。不合格でも提案として保存し、「要確認」と「推定」の印を表示する。

## 無料枠と失敗
| 項目 | 値 |
|---|---|
| 1日の上限（アプリ側） | 6,000ニューロン（管理画面で 0〜8,000）。Cloudflare の無料枠 10,000 とは別の余裕 |
| 予約 | 解析の前に「長さ÷60×46.63×1.2」を予約。失敗しても戻さない（安全側）。日付は世界標準時 |
| 同時に解析 | 1曲（データベースのロック。3つ同時に呼んでも1曲だけ：テスト済み） |
| 回数 | 5分ごとに1曲（1日最大288回。実際は上限で先に止まる） |
| 一時的な失敗 | 30分後 → 2時間後 → 3回目で打ち切り（運営の「やり直す」か本人の依頼まで再開しない） |
| 無料枠切れ（Cloudflare が 429・4006） | 翌日 0時5分（世界標準時）まで全体を止める。試行回数に数えない |
| トークン無効・設定不足 | 全体を停止（運営が直して「再開」するまで） |
| 解析中のまま止まった（10分） | 試行1回として数え、30分後に再試行 |
| 解析中に歌詞が変わった | 結果を捨てて解析待ちへ |
| 形式の違う結果 | 保存しない（打ち切り） |

## 停止と再開
- 管理画面 →「歌詞AI」→「停止する／再開する」（すぐ効く。解析中の1曲は終わってから止まる）
- 非常用：Edge Function の Secrets `AIMUSE_ALIGN_ENABLED` を消す（その時点で何もしなくなる）
- 定期実行を止める：`select cron.unschedule('aimuse-lyrics-align');`

## 本番導入の手順（6段階・それぞれ承認を取ってから）
1. **データベース**：v1.15 を適用（停止中）→ 既存データ・表の権限・RLS が変わらないこと、会員・未ログインが仕事用の関数を実行できないことを照合
2. **Edge Function と定期実行**：`lyrics-align` を配置（Secrets：`AIMUSE_ALIGN_ENABLED=1`・`CF_ACCOUNT_ID`・`CF_AI_TOKEN` は検証のものを使う）→ `cron_lyrics_align.sql` → 停止中のまま、呼び出しが「paused」で何もしないことを確認
3. **アプリの公開**（main へマージ・Cloudflare Pages）：管理画面「歌詞AI」・編集画面の下書き・プライバシーポリシーの追記（※会員の曲を解析する前に公開しておく）
4. **おぼろ月1曲**：管理画面で「この1曲を登録」→「再開」→ 約5〜10分で確認待ち → 編集画面で聞いて確かめて保存 → 再生画面で表示を確認 → 「停止」
5. **残り9曲**：「公開中の曲をまとめて登録」→「再開」→ 約1時間（約1,900ニューロン）→ 1曲ずつ確認して保存
6. **新しい投稿**：再開したままにする（承認されると自動で解析待ち）。検証用の `lyrics-align-probe` と関数3つを片付ける

## 元に戻す
1. 管理画面で「停止する」（または Secrets の `AIMUSE_ALIGN_ENABLED` を消す）
2. `select cron.unschedule('aimuse-lyrics-align');`
3. Supabase の画面 → Edge Functions → `lyrics-align` を削除
4. SQL Editor で `supabase/rollback/rollback_v1_15.sql`（同期の時刻は残る。AI の同期も消す場合は最後のコメントの1行）
